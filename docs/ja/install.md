# インストール

HiCarta はお使いの PC 上で動作するアプリです。専用サーバーの構築や HiCarta 用のアカウント登録は不要です。

Windows では、次の 3 ステップで起動できます。macOS での手順は、このページの末尾から参照できます。

## 1. R をインストールする

<https://cran.r-project.org> を開き、Windows 用の R（4.1 以上）をダウンロードしてインストールします。通常はインストーラーの既定の設定のまま進めれば完了します。

!!! note "RStudio は不要です"
    R 本体のみで動作します。RStudio が入っていても問題ありません。

## 2. HiCarta をダウンロードして展開する

GitHub のページ <https://github.com/rafysta/HiCarta> を開き、緑色の **「Code」** ボタン → **「Download ZIP」** をクリックします。

![](../images/download.png){ width="400" }

ダウンロードした ZIP ファイルを右クリックし、「すべて展開」を選びます。展開先はどこでも構いません（デスクトップなど分かりやすい場所がおすすめです）。

## 3. `run_windows.bat` をダブルクリックする

展開したフォルダ内の **`run_windows.bat`** をダブルクリックします。

初回起動時は必要な R パッケージが自動的にインストールされるため、数分かかることがあります。準備が終わると、ブラウザのタブが自動で開き、HiCarta が表示されます（アドレスは `http://127.0.0.1:7788`）。

2 回目以降は通常、短時間で起動します。アプリを終了するときは、ランチャーのウィンドウ（コマンドプロンプト）を閉じてください。

---

これで完了です。使い方は **[使い方](usage.md)**、画面の各項目の意味は **[画面と操作の説明](interface.md)** を参照してください。

起動できない場合や macOS をお使いの場合、また手動でインストールする場合は **[セットアップ詳細・トラブルシューティング](setup-details.md)** を参照してください。
