# データカタログ (.xlsx)

HiCarta のデータは、コンタクトマップもトラックもすべて**データカタログ**から開きます。カタログは普通の Excel ファイル（`.xlsx`）で、**1 行 = 1 サンプル**です。画面上部の **Data** ボタンで開く **Data browser** に読み込むと、絞り込み・検索のできるサンプル一覧として表示されます。行をクリックすると全情報が表示され、ファイル形式に応じた操作（コンタクトマップとして開く／比較として開く／トラックとして追加／IGV で開く）が選べます。

そのまま使えるテンプレートがリポジトリに入っています：
[`HiCarta_catalog_template.xlsx`](https://github.com/rafysta/HiCarta/blob/main/HiCarta_catalog_template.xlsx)

カタログはローカルパス・ネットワークドライブ・URL（HTTP で共有した `.xlsx` など）のどこに置いても構いません。**読み込み**を押すたびに読み直すので、共同研究者が共有ファイルを編集しても次の読み込みで必ず反映されます。Google スプレッドシートには対応していません（`.xlsx` として書き出して共有してください）。

---

## カラム

### 必須

| カラム | 意味 |
|---|---|
| `id` | カタログ内で**一意の数値**。ブックマークなどからサンプルを参照するのに使います。 |
| `name` | 一覧に表示するサンプル名。 |
| `path` | ファイルのパスまたは URL。`;` 区切りで**複数エントリ**を持てます（後述）。 |

### 推奨（HiCarta が認識するカラム）

| カラム | 意味 |
|---|---|
| `file_type` | `hic` / `bigwig` / `bed` / `gff3` / `bs`。空欄なら拡張子から推定。 |
| `experiment_type` | HiC、ChIP-seq、RNA-seq など。フィルタになります。 |
| `project` | プロジェクト名。フィルタになります。 |
| `sample_sheet` | サンプルシート／バッチの識別子。フィルタになります。 |
| `date` | `YYYY-MM-DD` 推奨。`YYYY/MM/DD`・`YYYY.MM.DD`・`YYYYMMDD`・Excel の日付セルも可。期間で絞り込めます。 |
| `genome` | ゲノム／アセンブリ名。 |
| `label` | `path` の `;` エントリごとの表示ラベル（`path` と同数、または 1 つで共通）。 |
| `comment` | 自由記述。全カラム検索の対象になります。 |

### 設定カラム（`set_` プレフィックス）

名前が `set_` で始まるカラムは、**そのサンプルを開くときに適用される既定値**です。一覧やフィルタには現れません。

| カラム | 開くときの効果 |
|---|---|
| `set_norm` | 選択する正規化（`ICE`・`KR`・`NONE` など）。未指定なら **ICE → KR → Raw** の優先順でファイルが持つものを自動選択。 |
| `set_vmax` | カラースケール最大値の初期値。 |
| `set_resolution` | 表示解像度（bp）をズーム連動でなく固定。 |
| `set_color` | トラックの既定色（トラック形式のとき）。 |
| `set_height` | トラックの既定高さ px（トラック形式のとき）。 |

### 自由カラム

それ以外のカラムも保持され、詳細表示に出ます。**異なる値が 20 個以下**のカラムは自動的にサイドバーのドロップダウンフィルタになるので、`tissue` や `condition` のような列を足すだけで絞り込みに使えます。

---

## 1 行に複数ファイル（`;`）

`path`・`label`・各 `set_` カラムは `;`（全角 `；` も可）区切りで複数の値を持てます。同じ行では、これらのカラムは **1 個**（全エントリ共通）か **`path` と同数**のどちらかです。

使い方は 2 つ：

- **トラックのセット** — 1 サンプルに属する複数の bigWig など。「トラックとして追加」でエントリを選べます。
- **仮想マルチ解像度データセット** — 同じサンプルの単一解像度 `.hic` を 1 行にまとめる。行を**「自動」**で開くと 1 つのデータセットとして扱い、ズームに応じてファイルを切り替え、明るさも揃えます。これは既存の解像度別ファイルのための互換機能で、新しいデータは 1 つのマルチ解像度 `.hic` にするのが推奨です。

!!! note
    「自動」では**全ファイルに共通する正規化**だけが「表示 → マップ → 正規化」に並びます。特定ファイルの正規化を使うには、そのエントリを単独で開いてください。

---

## ディレクティブ行：`#show`

`id` セルが `#show` の行はデータではありません。**最初から一覧に表示したいカラム**に何か（例: `1`）を入れてください。表示カラムは **Columns** ボタンでいつでも変えられます。`id` と `name` は常に表示されます。`#` で始まるが未知のディレクティブの行は警告つきで無視されます。

---

## バリデーション

カタログ読み込み時、壊れた行 — `id` の欠落・重複・非数値、`path` が空、`;` の個数不一致 — は**除外**され、サンプル名と理由つきで表の上に一覧表示されます。軽微な問題（解釈できない日付、未知の `file_type` や `set_` カラム）は警告のみで、行は読み込まれます。

---

## ブックマークの Excel 入出力

ブックマーク（**移動**パネル）は場所だけでなく**開いていたデータ**（カタログ id・パス・正規化・解像度・カラースケール最大値）も記憶し、クリックすると表示全体を復元します。`.xlsx` との入出力は 2 つのボタンで行います：

- **Excel に保存** — 現在のリストをダウンロード（1 行 = 1 ブックマーク。カラムは `bookmark_name, catalog_id, path, entry, chr, start, end, ystart, yend, norm, resolution, vmax, comment`）。
- **Excel から読み込み（追加）** — ファイルの行を現在のリストに**追加**します。既存のブックマークには触れません。壊れた行はカタログと同様、名前と理由つきで報告されスキップされます。

ただの Excel ファイルなので、`comment` 列に注釈を書く、注目領域のリストを手で作る、共同研究者と共有する、といった使い方ができます。

---

## IGV で開く

トラック行の詳細表示には **IGV で開く**ボタンがあります。ファイル（と現在表示中の領域）を、**起動済みの IGV デスクトップ**に IGV のリモートポート経由で送ります。HiCarta が IGV を起動することはありません — IGV は自分で起動し、一度だけポートを有効にしてください：*View → Preferences → Advanced → 「Enable port」*（既定 60151）。`config.txt`（または **Setting → Edit config file…**）の `igv_genome` を設定すると、読み込むゲノムも IGV に伝えます。

---

## 旧形式との変換

`scripts/` に、カタログと 2 つの旧形式（Juicer 形式メニュー、IGV トラックリスト XML）を相互変換する単体スクリプトが 4 つ入っています：

```bash
Rscript scripts/juicer_menu_to_catalog.R  menu.txt     catalog.xlsx [--collapse]
Rscript scripts/igv_xml_to_catalog.R      tracks.xml   catalog.xlsx
Rscript scripts/catalog_to_juicer_menu.R  catalog.xlsx menu.txt
Rscript scripts/catalog_to_igv_xml.R      catalog.xlsx tracks.xml
```

`--collapse` を付けると、正規化別の旧ファイル名（`NAME_ICE.5kb.hic` → `NAME.hic`）を書き換えて重複を除きます。データを単一のマルチ解像度 `.hic` として再生成した後に便利です。詳しくは
[scripts/README.md](https://github.com/rafysta/HiCarta/blob/main/scripts/README.md) を参照してください。
