# 画面と操作の説明

このページは、HiCarta の各メニューと項目が何をするものかを詳しく説明するリファレンスです。「まず何をすればよいか」を知りたい場合は **[使い方](usage.md)** を先にご覧ください。

画面上部には次のメニューがあります: **データ · 移動 · 表示 · 印刷 · 設定 · 情報**。**データ** ボタンを押すと読み込み画面が開き、その他のメニューは画面左の操作パネルを切り替えます。**表示** パネルには **マップ · 比較 · トラック** の 3 つのタブがあります。

典型的な流れは、カタログを読み込む → サンプルをクリックして開く → 移動・ズーム → トラックを追加、です。

---

## データ（読み込み画面） {#data}

上部の **データ** ボタンを押すと、読み込み画面が開きます。**Data browser** / **セッション** の 2 つのタブがあります。

### Data browser タブ

コンタクトマップもトラックも、すべてのデータは **[データカタログ](data-catalog.md)**（1 行 = 1 サンプルの Excel ファイル）から開きます。

**カタログを読み込む** — パス/URL 欄には `config.txt` の `catalog_url` が入っています。**参照…** でローカルファイルも選べます。**読み込み** で（再）読み込みします。壊れた行は除外され、サンプル名と理由つきで表示されます。

**絞り込みと検索** — 左サイドバーには、サンプル名のインクリメンタル検索、全カラム検索（コメント含む）、カタログのカラムから自動生成されるドロップダウンフィルタ、日付の期間フィルタがあります。条件はすべて AND で組み合わされ、各ドロップダウンには他の条件に合致する値だけが並びます。

**サンプル一覧** — 表示カラムは **Columns** ボタン、ページあたりの件数はその隣で変えられます。行をクリックすると**詳細表示**が開き、全カラムの内容と、ファイル形式に応じた操作が並びます：

- **コンタクトマップとして開く** — `hic` の行。`;` 区切りで複数の `.hic` を持つ行は、**仮想マルチ解像度データセット**（「自動」）として束ねて開くことも、1 エントリだけ開くこともできます。
- **比較 (B) として開く** — 2 つ目のマップを読み込んで比較します（表示 → 比較）。
- **トラックとして追加** — トラックの行（`bigwig` / `bed` / `gff3` / `bs`）。次のダイアログでラベル・色（ビジュアルパレット）・高さを設定してから追加します。カタログの `set_*` カラムが初期値になります。
- **IGV で開く** — トラックの行。ファイルと現在の表示領域を起動済みの IGV に送ります（[詳細](data-catalog.md#igv-で開く)）。

マップを開くときにはカタログの `set_norm`・`set_vmax`・`set_resolution` が適用されます。`set_norm` がなければ、ファイルが持つ正規化から **ICE → KR → Raw** の優先順で自動選択します。

### セッションタブ

表示全体をファイルに保存・復元します。

**現在の表示を保存** — データ元・領域・カラースケール・すべてのトラックを含む表示状態を、`.json` ファイルとしてダウンロードします（ファイル名は `HiCarta_session_日時.json`）。

**ファイルから復元（.json）** — 保存しておいた `.json` を選ぶと、その表示を丸ごと再現します。

## 移動 {#navigate}

表示する染色体と領域を指定し、マップ上を移動します。

**染色体** — 表示する染色体を選びます。染色体名は `.hic` の内部名に従います（例: *S. pombe* では `I / II / III`）。別の染色体を選ぶと、マップは自動的に開き直されます。

**Y 軸 開始 / Y 軸 終了（bp）** — 表示する範囲を bp で指定します。

**領域へ移動** — 入力した染色体・範囲へジャンプします。

**画面移動（方向パッド）** — 上下左右＋斜めの 8 方向ボタンで、表示中の領域を動かします。上下は Y 軸方向、左右は X 軸方向の移動です。中央の **⌂**（ホーム）ボタンで、その染色体の全体表示に戻ります。

**移動量** — 方向ボタン 1 回あたりの移動量を、表示範囲に対する割合（**¼ · ½ · 1**）で選びます。

**ブックマーク** — 今見ている表示を保存し、あとから戻れます。名前欄（省略可）に名前を入れ、**★ この表示を保存** で登録します。ブックマークは場所だけでなく**開いていたデータ**（カタログ id・パス・正規化・解像度・カラースケール最大値）も記憶するので、クリックすると表示全体が復元されます。**削除** で消去します。ブックマークはセッションにも保存されるほか、Excel との入出力ができます：**Excel に保存** で一覧をダウンロード、**Excel から読み込み（追加）** でファイルの行を追加します（[詳細](data-catalog.md#ブックマークの-excel-入出力)）。

## 表示 {#display}

**マップ** タブは開いているマップの調整、**比較** タブは 2 サンプル比較（比較の解除もここ）、**トラック** タブは[下記](#tracks)を参照してください。

カラースケールを調整します。色は全タイル共通の **1 つの絶対値スケール** を使うため、タイルの継ぎ目が出ません。

**正規化** — 開いているマップの正規化（ICE / KR / Raw など）を、開き直さずに切り替えます。選択肢は `.hic` ファイルが実際に持つものです。仮想マルチファイルデータセット（「自動」）では、全ファイルに共通する正規化だけが並びます。

**解像度** — スライダーでビンサイズを固定できます（**自動** ならズームに連動）。選択肢には、その染色体が現在の正規化で実際に持っている解像度だけが並びます。`.hic` のヘッダはファイル全体の解像度を並べますが、染色体ごとの行列はより少ないズームレベルしか持たないことがあり、正規化ベクトルが一部の解像度に無いこともあるためです。したがって染色体や正規化によって、拡大が粗いビンサイズで止まることがあります（ビューアの制限ではなくデータ側の理由です）。

**カラーパレット** — 配色を選びます（matlab, gentle, red, blue の 4 種類）。

**最大値（Max）** — このスライダーを動かすとコントラストが変わり、すべてのタイルが再描画されます。初期値は、マップを開いたときに全体を粗く走査して自動で推定されます。

**線形 / log10(値)** — 値スケールの取り方を切り替えます。最小値は 0 に固定されています。

## トラック（表示 → トラック） {#tracks}

コンタクトマップの下に 1 次元トラックを重ねて表示します。トラックはマップの横方向の移動・ズームに追従し、表示中の範囲だけを読み込みます。複数のトラックを、個別の色と高さで積み重ねられます。カーソルのガイド線がトラックを貫いて表示されます。

トラックはカタログから追加します：**Data browser** でトラックの行をクリックし、**トラックとして追加** を選びます。追加前のダイアログでラベル・色（ビジュアルパレット）・高さを設定できます。カタログの `set_color` / `set_height` が初期値になります。

**表示 → トラック** パネルには、追加済みのトラックが**チップ**として並びます。チップをドラッグすると並び順（＝描画順）が変わります。チップをクリックするとそのトラックの編集ダイアログが開き、ラベル・色・高さ・最大値・集計方法・トラックごとの解像度の変更や、削除ができます。

トラックは**コンタクトマップなし**でも使えます。最初のトラックファイルから染色体の軸が読み取られ、上部に座標ルーラーが表示されます。ルーラー上を範囲ドラッグするとその範囲にズームします。

扱えるトラックの種類:

| 種類 | 表示内容 | 備考 |
|---|---|---|
| **bigWig** | 塗りつぶし面 | `rtracklayer` で読み込み |
| **BED** | 区間のボックス | `rtracklayer` で読み込み |
| **遺伝子（GFF3）** | 遺伝子の矢印・エクソン・名前 | ＋鎖は上／−鎖は下。ズームインでエクソン表示。名前は重ならないよう間引き。`<gff3>.genes.rds` にキャッシュ |
| **境界強度（Border Strength）** | `BS.norm` の面 | 正＝赤、負＝青、基準線 0。境界に破線 |

各形式の詳細は **[データ形式](data-formats.md)** を、トラックを記述するカタログのカラムは **[データカタログ](data-catalog.md)** を参照してください。

## 印刷 {#print}

現在開いているマップの指定領域を、画像または PDF として出力したり、印刷したりします。

**印刷プレビューを開く** をクリックすると、プレビュー画面が開きます。プレビューでは次を設定できます。

- **送信先** — プリンター、またはファイル。
- **出力フォルダ / ファイル名 / フォーマット** — ファイル出力時の保存先とファイル名、フォーマット（**画像（PNG）** または **PDF**）。
- **用紙サイズ** — A4 縦・A4 横・正方形・カスタム（幅・高さを mm で指定）。
- **出力領域** — 染色体・開始・終了（bp）。Hi-C では縦・横は同一範囲になります。
- **座標目盛を入れる / 凡例を入れる / 余白を空けない** — 出力に含める要素の切り替え。
- **トラックも出力する** — 表示中のトラックを一緒に出力します。

設定したら **実行** をクリックします。

## 設定 {#setting}

レイアウトとアプリの既定値を調整します。

**コンタクトマップの高さ（px）** — マップの高さを指定します。**適用** で反映します。

**ウィンドウに合わせる** — マップの高さを「ウィンドウの高さ − トラック高さの合計」に合わせます。

**トラック解像度（表示分割数）** / **自動調整** — トラックの描画解像度や高さを調整します。

**集計方法（染色体全体表示）** — 全体表示のときの集計を、**平均（IGV 既定）** か **最大（ピーク保持）** から選びます。

### 設定ファイルを編集…

**設定ファイルを編集…** を押すと、アプリ起動時の既定値（`config.txt`）を確認・編集できます。

- **表示言語** — 日本語 / 英語を切り替えます。
- **既定のカタログ (.xlsx) URL / パス** — Data browser に既定で読み込むデータカタログ。
- **リモートファイルの読み込み方式** — ストリーミング（既定）か、ファイル全体を先にダウンロードするか。
- **IGV のゲノム ID** — 「IGV で開く」で一緒に送るゲノム（例: `hg38`。空欄なら送信しない）。

**設定を反映** をクリックすると、ページが再読み込みされて設定が適用されます（このとき、現在読み込んでいるマップやトラックは閉じられます）。

## マップ上での操作

マップを開いたあとは、マップ上で直接操作できます。

- **ドラッグ** で移動
- **スクロール** でズーム（解像度は自動で切り替わります）
- **中クリックのドラッグ** で範囲指定のズーム（ラバーバンド）

ヘッダーには現在の座標と解像度が表示され、端には目盛り付きのルーラーが出ます。カーソルを合わせると、その位置の座標・スコア・距離が表示されます。座標系は左上が原点で、ゲノム座標の *y* は下向きに増加します。

---

## 注意と対応範囲

- HiCarta は現在、**cis**（同一染色体内）のコンタクトを対象としています。
- トラックの染色体名（例: `chrII`）は、可能な範囲で `.hic` の名前（`II`）に対応付けられます。
