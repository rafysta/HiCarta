# 画面と操作の説明

このページは、HiCarta の各メニューと設定項目の機能を詳しく説明するリファレンスです。「まず何をすればよいか」を知りたい場合は **[使い方](usage.md)** を先にご覧ください。

画面上部には次のメニューがあります： **データ · 移動 · 表示 · 印刷 · 設定 · 情報**。**データ** ボタンを押すと読み込み画面が開き、その他のメニューは画面左の操作パネルを切り替えます。**表示** パネルには **マップ · 比較 · トラック** の 3 つのタブがあります。

基本的な操作の流れは、カタログの読み込み → サンプルの選択・表示 → 移動・ズーム → トラックの追加です。

---

## データ（読み込み画面） {#data}

上部の **データ** ボタンを押すと、読み込み画面が開きます。**データブラウザ** / **ファイル指定** / **セッション** の 3 つのタブがあります。

### データブラウザタブ

コンタクトマップやトラックは **[データカタログ](data-catalog.md)**（1 行につき 1 サンプルの情報を記載した Excel ファイル）から開けます。

**カタログを読み込む** — パスまたは URL の欄には `config.txt` の `catalog_url` が入っています。**参照…** でローカルファイルも選べます（場所の一覧には、登録した**お気に入りのフォルダ**（★）、**デスクトップ / ドキュメント / ダウンロード / ホーム** の順に並び、その後にドライブが続きます。Windows で OneDrive にリダイレクトされたデスクトップも正しく開きます）。**カタログを読み込む** をクリックすると、カタログが読み込まれます（再読み込みも可能です）。不正な行は除外され、サンプル名と除外理由が表示されます。

**絞り込みと検索** — 左サイドバーには、サンプル名の逐次検索（入力に応じた検索）、全カラム検索（コメントを含む）、カタログのカラムから自動生成されるドロップダウンフィルタ、日付範囲による絞り込みがあります。条件はすべて AND で組み合わされ、各ドロップダウンには他の条件に合致する値だけが並びます。

**サンプル一覧** — 表示カラムは **Columns** ボタン、1 ページあたりの表示件数は隣の項目で変更できます。行をクリックすると**詳細表示**が開き、全カラムの内容と、ファイル形式に応じた操作が表示されます。

- **コンタクトマップとして開く** — `hic` の行。`;` 区切りで複数の `.hic` を持つ行は、**仮想マルチ解像度データセット**（「自動」）としてまとめて開くことも、1 エントリだけ開くこともできます。
- **比較 (B) として開く** — 2 つ目のマップを読み込んで比較します（表示 → 比較）。
- **トラックとして追加** — トラックの行（`bigwig` / `bed` / `gff3` / `bs`）。次のダイアログでラベル・色（ビジュアルパレット）・高さを設定してから追加します。カタログの `set_*` カラムが初期値になります。
- **IGV で開く** — トラックの行。ファイルと現在の表示領域を起動済みの IGV に送ります（[詳細](data-catalog.md#open-in-igv)）。

マップを開くときにはカタログの `set_norm`・`set_vmax`・`set_resolution` が適用されます。`set_norm` がなければ、ファイル内で利用できる正規化方法から **ICE → KR → Raw** の優先順で自動選択します。

### ファイル指定タブ

カタログに登録していないファイルを、パスまたは URL を直接指定して開きます。カタログの `set_*` による既定値（正規化・カラースケール最大値・解像度・色・高さ）は適用されないので、必要に応じて読み込み後に **表示** で調整してください。

**コンタクトマップ (.hic)** — パスまたは URL を入力（**参照…** でローカルファイルも選択できます）し、必要なら正規化と表示名を指定して、**コンタクトマップとして開く** または **比較 (B) として開く** を押します。解像度が 1 種類のファイルをまとめて仮想マルチ解像度データセットとして開くときは、パスを `;` で区切って並べます（比較 B は常に 1 ファイルのみで、先頭のパスが使われます）。

**トラック** — パスまたは URL を入力し、**種類** を選んで（**自動** は拡張子から `bigWig` / `BED` / `遺伝子 (GFF3)` / `Border Strength` を判定します）、ラベル・色・高さを決めて **トラックを追加** を押します。

ここから開いたデータもセッションに保存できます。ブックマークには、カタログから開いた場合と同様にゲノム上の位置だけが記録されます。

### セッションタブ

表示全体をファイルに保存・復元します。

**現在の表示を保存** — データの参照先・領域・カラースケール・すべてのトラックを含む表示状態を、`.json` ファイルとしてダウンロードします（ファイル名は `HiCarta_session_日時.json`）。

**ファイルから復元（.json）** — 保存しておいた `.json` のパスまたは URL を入力し（**参照…** でローカルファイルも選択できます）、**読み込む** を押すと、保存した表示状態を復元します。

## 移動 {#navigate}

表示する染色体と領域を指定し、マップ上を移動します。

**染色体（X軸）** — 表示する染色体を選びます。染色体名には `.hic` 内の名称を使用します（例：*S. pombe* では `I / II / III`）。別の染色体を選ぶと、マップは自動的に開き直されます。染色体の一覧は、マップを開くたびにファイルから読み込まれます。

**X 軸 開始 / X 軸 終了（bp）** — 表示する範囲を bp で指定します。

**全染色体（ゲノム全体）** — X軸の染色体リストの先頭にあります。縦横の両軸が全染色体を連結したものになり、すべての染色体の組み合わせが一度に表示されます。対角線上に各染色体の cis マップが並び、その外側のブロックが染色体間マップです。両方の目盛りに染色体名が表示され、境界には細い罫線が入ります。カーソルの表示も、染色体名とその中での位置になります。移動・ズーム・カラースケール・ブックマーク・比較表示・出力は通常どおり使えます。トラックはこの表示の間だけ非表示になります（トラックは 1 本の染色体の座標に沿って描画されるためです）。個別の染色体を選び直すと、トラックが再表示されます。

**染色体（Y軸）** — **X軸と同じ（通常のマップ）** のままなら、通常の 1 本の染色体の正方形マップです。*別の*染色体を選ぶと、その 2 本の染色体間の **染色体間（trans）マップ** を描画します。横軸は X 軸の染色体のまま、縦軸が選んだ染色体になるため、マップは正方形ではなく長方形になります。左上のバッジに、どちらの軸がどの染色体かが表示されます。トラックは常に横軸に従うので、染色体間マップでも X 軸のゲノム座標に対応します。

**Y 軸 開始 / Y 軸 終了（bp）** — 縦軸の範囲で、2 つの軸が異なるときだけ表示されます。Y 軸の染色体を選ぶと、その染色体の全長が自動で入ります。

染色体間マップには対角線がなく対称でもないため、次の点で動作が異なります。比較表示の **対角分割** は選べません（カーテン表示または差分表示をお使いください）。また、カーソルの表示から 2 点間の距離が省かれます。

**領域へ移動** — 指定した染色体・範囲へ移動します。

**画面移動（方向パッド）** — 上下左右＋斜めの 8 方向ボタンで、表示中の領域を動かします。上下は Y 軸方向、左右は X 軸方向の移動です。中央の **⌂**（ホーム）ボタンで、その染色体の全体表示に戻ります。

**移動量** — 方向ボタン 1 回あたりの移動量を、表示範囲に対する割合（**¼ · ½ · 1**）で選びます。

**ブックマーク** — 注目している領域を登録し、あとからワンクリックで戻れます。名前欄（省略可）に名前を入力し、**★ この表示を保存** で登録します。ブックマークが記録するのは**場所だけ**（染色体と X／Y の範囲）で、データの参照先や表示設定は記録しません。クリックすると**いま開いているデータの中で**その領域へ移動するので、同じブックマークをサンプルごとに繰り返し利用して比較できます。正規化・解像度・カラースケールは現在の設定のままです。**削除** で消去します。ブックマークはセッションにも保存されるほか、Excel ファイルの入出力にも対応しています。**Excel に保存** で一覧をダウンロード、**Excel から読み込み（追加）** の欄にパスまたは URL を入力し（**参照…** でローカルファイルも選択できます）、**読み込む** でファイルの行を追加します（[詳細](data-catalog.md#bookmarks-as-excel)）。

## 表示 {#display}

**マップ** タブは開いているマップの調整、**比較** タブは 2 サンプル比較（比較の解除もここ）、**トラック** タブは[下記](#tracks)を参照してください。

カラースケールを調整します。すべてのタイルで共通の **カラースケール** を使用するため、タイル間で色の尺度が統一されます。

**正規化** — 開いているマップの正規化（ICE / KR / Raw など）を、開き直さずに切り替えます。選択肢には `.hic` ファイル内で利用できる正規化方法が表示されます。仮想マルチファイルデータセット（「自動」）では、全ファイルに共通する正規化だけが並びます。

**解像度** — スライダーでビンサイズを固定できます（**自動** ならズームに連動）。選択肢には、その染色体が現在の正規化で実際に持っている解像度だけが並びます。`.hic` のヘッダーにはファイル全体の解像度の一覧が記録されていますが、染色体ごとの行列は利用できる解像度が限られる場合があり、一部の解像度で正規化ベクトルがないこともあるためです。したがって染色体や正規化によって、拡大が粗いビンサイズで止まることがあります（データ側の制約によるものです）。

**カラーパレット** — 配色を選びます（matlab, gentle, red, blue の 4 種類）。

**最大値（Max）** — このスライダーを動かすとコントラストが変わり、すべてのタイルが再描画されます。初期値は、マップを開いたときに全体を粗く走査して自動で推定されます。

**線形 / log10(値)** — 値のスケールを切り替えます。最小値は 0 に固定されています。

## トラック（表示 → トラック） {#tracks}

コンタクトマップの下に 1 次元トラックを重ねて表示します。トラックはマップの横方向の移動・ズームに追従し、表示範囲に対応するデータを描画します。複数のトラックを、個別の色と高さで積み重ねられます。カーソル位置を示すガイド線がトラックにも表示されます。

カタログからトラックを追加するには、**データブラウザ** でトラックの行をクリックし、**トラックとして追加** を選びます。追加前のダイアログでラベル・色（ビジュアルパレット）・高さを設定できます。カタログの `set_color` / `set_height` が初期値になります。

**表示 → トラック** パネルには、追加済みのトラックが**チップ**として並びます。チップをドラッグすると並び順（＝描画順）が変わります。チップをクリックするとそのトラックの編集ダイアログが開き、ラベル・色・高さ・最大値・集計方法・トラックごとの解像度の変更や、削除ができます。

トラックは**コンタクトマップなし**でも使えます。最初のトラックファイルから染色体の軸が読み取られ、上部に座標ルーラーが表示されます。ルーラー上を範囲ドラッグするとその範囲にズームします。

主なトラックの種類は次のとおりです。

| 種類 | 表示内容 | 備考 |
|---|---|---|
| **bigWig** | 塗りつぶし面 | 表示範囲だけを部分的に読み込み（リモートのファイルも全体をダウンロードしない） |
| **BED** | 区間のボックス | ファイル全体を読み込み（`rtracklayer`） |
| **遺伝子（GFF3）** | 遺伝子の矢印・エクソン・名前 | プラス鎖は上、マイナス鎖は下に表示。ズームインするとエクソンを表示。遺伝子名は重なりを避けて間引く。`<gff3>.genes.rds` にキャッシュ |
| **境界強度（Border Strength）** | `BS.norm` の面 | 正＝赤、負＝青、基準線 0。境界に破線 |

各形式の詳細は **[データ形式](data-formats.md)** を、トラックを記述するカタログのカラムは **[データカタログ](data-catalog.md)** を参照してください。

## 印刷 {#print}

現在開いているマップやトラックの指定領域を画像または PDF として出力したり、印刷したりできます。

**印刷プレビューを開く** をクリックすると、プレビュー画面が開きます。プレビューでは次を設定できます。

- **送信先** — プリンター、またはファイル。
- **出力フォルダ / ファイル名 / フォーマット** — ファイル出力時の保存先とファイル名、フォーマット（**画像（PNG）** または **PDF**）。
- **用紙サイズ** — A4 縦・A4 横・正方形・カスタム（幅・高さを mm で指定）。
- **出力領域** — 各軸の染色体・開始・終了（bp）。**染色体（Y軸）** を *X軸と同じ* のままにすると通常の正方形マップ、別の染色体を選ぶとその 2 本の染色体間の染色体間マップを出力します。
- **解像度** — *画面のマップと同じ* のままにすると、画面と同じ解像度で出力します（表示 → マップ で固定した解像度もそのまま反映されます）。画面の表示と同じ色のスケールを利用できます。ここで解像度を選ぶとそちらが優先されます。実際に使われた解像度は、プレビューの下の行に必ず表示されます。
- **縦横のスケールを揃える** — 既定でオンです。1 bp あたりの描画上の長さが縦横で同じになるため、領域が歪むことがありません。余った領域にはマップが中央寄せで配置されます。オフにすると、従来どおり用紙の描画領域に合わせて拡大・縮小して描画します。どちらの場合もトラックはマップと横位置が揃います。染色体間マップでは、領域の縦横比に近い用紙サイズを選ぶと余白が小さくなります。
- **座標目盛を入れる / 凡例を入れる / 余白を空けない** — 出力に含める要素の切り替え。
- **トラックも出力する** — 表示中のトラックを一緒に出力します。

設定したら **実行** をクリックします。

## 設定 {#setting}

レイアウトとアプリの既定値を調整します。

**コンタクトマップの高さ（px）** — マップの高さを指定します。**適用** で反映します。

**ウィンドウに合わせる** — マップの高さを「ウィンドウの高さ − トラック高さの合計」に合わせます。

**トラック解像度（表示分割数）** / **自動調整** — トラックの描画解像度や高さを調整します。

**集計方法（染色体全体表示）** — 全体表示のときの集計を、**平均（IGV 既定）** か **最大（ピーク保持）** から選びます。

### 設定ファイルを編集…

**設定ファイルを編集…** を押すと、アプリ起動時の既定値（`config.txt`）を確認・編集できます。

- **表示言語** — 日本語 / 英語を切り替えます。
- **既定のカタログ (.xlsx) URL / パス** — データブラウザに既定で読み込むデータカタログ。
- **リモートファイルの読み込み方式** — ストリーミング（既定）か、ファイル全体を先にダウンロードするか。
- **IGV のゲノム ID** — 「IGV で開く」で一緒に送るゲノム（例：`hg38`。空欄なら送信しない）。
- **お気に入りのフォルダ** — すべての **参照…** ダイアログの場所の一覧の先頭に ★ 付きで並ぶフォルダ。1 行に 1 つ、`表示名 = パス`（パスだけでも可）。**フォルダを追加…** でフォルダを選択して追加できます。存在しないフォルダは表示されません。

**設定を反映** をクリックすると、ページが再読み込みされて設定が適用されます（このとき、現在読み込んでいるマップやトラックは閉じられます）。

## マップ上での操作

マップを開いた後は、マップ上で直接操作できます。

- **ドラッグ** で移動
- **スクロール** でズーム（解像度は自動で切り替わります）
- **マウスの中ボタンを押したままドラッグ** で範囲指定のズーム（ラバーバンド）

ヘッダーには現在の座標と解像度が表示され、マップの端には座標目盛が表示されます。カーソルを合わせると、その位置の座標・スコア・距離が表示されます。座標系は左上が原点で、ゲノム座標の *y* は下向きに増加します。

## 注意と対応範囲

- HiCarta は、**cis**（同一染色体内）と **trans**（染色体間）の両方のコンタクトを表示できます。染色体間のマップは、**移動** パネルで Y 軸に別の染色体を選ぶか、**全染色体（ゲノム全体）** を選ぶと表示されます（[移動](#navigate)）。
- トラックの染色体名（例：`chrII`）は、可能な範囲で `.hic` の名前（`II`）に対応付けられます。
